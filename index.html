Dashboard de Universidades en Buenos Aires

Este dashboard presenta un análisis visual de la distribución de universidades en la Ciudad de Buenos Aires. Incluye gráficos interactivos, métricas clave, filtros globales y un heatmap geográfico para mejorar la integración y el análisis.

Justificación de las visualizaciones

Se eligieron gráficos complementarios para cubrir diferentes necesidades de análisis:

  • El gráfico de barras permite comparar la cantidad de universidades entre barrios de forma clara y ordenada.
  • El gráfico de torta muestra la proporción de universidades por comuna y ayuda a entender la distribución relativa.
  • El mapa interactivo ofrece la visualización puntual de cada institución y facilita la exploración de ubicaciones.

Los filtros permiten seleccionar universidades por comuna o barrio. Al aplicar un filtro, se actualizan automáticamente todos los gráficos, KPIs y el mapa para mostrar solo los datos filtrados. Puedes combinar filtros o usar el botón "Reiniciar filtros" para ver todos los datos.

Gráfico de Barras: Universidades por Barrio

Este gráfico muestra la cantidad de universidades en cada barrio usando barras horizontales para una mejor legibilidad. Sirve para identificar dónde se concentra la oferta académica y cuáles barrios tienen mayor presencia institucional.

Las barras están ordenadas de mayor a menor y puedes hacer clic en cada barra para aplicar el filtro y centrar el mapa en ese barrio.

Gráfico de Torta: Distribución por Comuna

Este gráfico muestra la proporción de universidades en cada comuna. Es útil para entender la distribución territorial y qué comunas agrupan la mayor parte de las instituciones.

Haz clic en una comuna para aplicar el filtro y centrar el mapa en la comuna seleccionada.

Mapa Interactivo de Ubicaciones

El mapa muestra la ubicación geográfica de cada universidad. Al hacer clic en los marcadores se puede ver el nombre, barrio y comuna de cada institución.

Universidades por Comuna

Selecciona una comuna para ver qué universidades están ubicadas allí y cómo se distribuyen.
